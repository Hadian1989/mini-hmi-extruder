# Mini-HMI Extruder

Eine kleine Bedienoberfläche (HMI) für eine simulierte Extruder-Heizzone – mit reinem HTML, CSS und JavaScript.

🔗 **Live-Demo:** https://hadian1989.github.io/mini-hmi-extruder/

## Funktionen

- Motor starten und stoppen
- Simulierte Temperatur
- Einstellbarer Grenzwert (50–250 °C, ungültige Eingaben werden begrenzt)
- Alarm bei Übertemperatur
- Alarmprotokoll mit Uhrzeit (ein Eintrag pro Alarm)
- Not-Aus mit Quittierung (Wiederanlaufschutz)

## Starten

`index.html` im Browser öffnen.
